# HBO Max — Projeto DIO

Projeto acadêmico desenvolvido como exercício prático de **HTML5 e CSS3**, com uma página inspirada na apresentação de planos e conteúdos da HBO Max.

O objetivo é praticar estruturação semântica, organização de arquivos, estilização, efeitos de interação e responsividade.

## Demonstração

A página contém:

- Cabeçalho com identificação visual e botões de acesso.
- Banner principal com chamada para assinatura.
- Seção de planos com alternância entre valores mensais e anuais.
- Cards de categorias, estreias e gêneros.
- Área de perguntas frequentes expansíveis.
- Rodapé com links demonstrativos.

## Tecnologias utilizadas

- **HTML5** — estrutura e conteúdo da página.
- **CSS3** — layout, cores, tipografia, efeitos de hover e responsividade.
- **Git e GitHub** — versionamento e publicação do projeto.

O projeto foi construído com HTML e CSS puros, sem frameworks ou bibliotecas JavaScript.

- Efeitos de hover e transições nos botões e cards.
- Destaque visual ao passar o mouse sobre os elementos interativos.
- Alternância entre preços mensais e anuais feita com controles `radio` e CSS.
- Perguntas frequentes que abrem e fecham com os elementos HTML `details` e `summary`.
- Navegação interna por links de âncora.
- Estados de foco para facilitar a navegação pelo teclado.

## Responsividade

O layout utiliza CSS Grid, Flexbox e media queries para adaptar a apresentação a diferentes larguras de tela, incluindo computadores, tablets e celulares.

## Observações

Este projeto é uma **reprodução educacional e não oficial**, criada para fins de estudo e portfólio. Não possui integração com sistemas de pagamento, login ou assinatura. Os botões são demonstrativos e conduzem a seções da própria página.

Os pôsteres e artes foram representados por composições visuais feitas em CSS; não são imagens oficiais das produções. HBO Max, suas marcas e os títulos mencionados pertencem aos respectivos titulares.
